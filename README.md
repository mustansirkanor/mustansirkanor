## Featured Work

### IGRIS — Edge Cloud OS

> A personal edge-cloud platform that turns laptops, phones, servers, cameras, and services into one secure, manageable system.

- Built a multi-node environment using **Tailscale, Docker, PostgreSQL, Redis, API gateways, service registries, and health monitoring**.
- Designed modules for remote development, deployment control, camera streaming, media hosting, semantic document retrieval, and CLI-based orchestration.
- Developing IGRIS as an extensible foundation where infrastructure services and AI capabilities can evolve independently without becoming tightly coupled.

`Distributed Systems` `Edge Computing` `Docker` `Tailscale` `PostgreSQL` `Redis` `RAG`

---

### AIOS — Agentic Intelligence OS

> A modular desktop intelligence layer designed to see, think, remember, and act safely.

- Designed a **seven-layer agent architecture** with screen understanding, file automation, anomaly awareness, voice interaction, and a rollback-oriented safety layer.
- Built a three-tier memory system spanning session context, structured long-term storage, and semantic retrieval.
- Combined **FastAPI, WebSockets, SQLite, ChromaDB, vision models, and speech interfaces** into a unified assistant architecture.

`Agentic AI` `Vision` `Whisper` `FastAPI` `ChromaDB` `WebSockets`

---

### Arise — AI Productivity Platform

> A gamified productivity system where real tasks become quests, progress becomes XP, and planning adapts to user behavior.

- Created an **E-to-S rank progression system**, weighted XP, streaks, quests, penalties, leaderboards, and real-time progress updates.
- Integrated a **LangGraph multi-agent workflow** that generates quests and adjusts their difficulty based on user activity.
- Implemented JWT authentication, Redis-backed sessions and caching, PostgreSQL history, rate limiting, and Socket.io notifications.

`React` `Node.js` `LangGraph` `PostgreSQL` `Redis` `Socket.io`

---

### CodiSched — Agentic Scheduler Intelligence

> A research-oriented system that learns when to use different CPU scheduling strategies.

- Implemented simulator-driven comparisons across **Round Robin, MLFQ, and Priority scheduling**.
- Built teacher-label generation, workload-aware oracle comparisons, and a fast student decision policy.
- Reached **97% teacher-imitation accuracy** with sub-millisecond policy decisions while preserving LLM fallback for unfamiliar workloads.
- Extending the system toward online scheduler switching, workload memory, and research-grade evaluation.

`Operating Systems` `ML Policy` `Scheduling` `Simulation` `Agentic Control`

## Research

### LiverGuard — Liver Tumor Prediction from Medical Imaging

Designed a two-stage pipeline using **Attention U-Net** for liver and tumor segmentation and a **Swin Transformer** for tumor prediction across 131 CT volumes.

- Liver/tumor Dice scores: **0.95 / 0.92**
- Classification accuracy: **98.6%**
- Inference time: **1.8 seconds**
- Evaluated through **8+ ablation studies**
- Status: **Under review**

### ShieldFed — Secure Federated Explainability for Precision Agriculture

Developed a privacy-preserving federated XAI framework based on a centrally trained LightGBM model, SHAP-centroid communication, differentially private client updates, and robust aggregation.

- Model accuracy: **99.32%**
- Compressed explanation lookup: **61.88 KB INT8**
- Designed for lightweight edge deployment
- Status: **Under review**
